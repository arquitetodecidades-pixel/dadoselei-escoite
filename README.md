# Mapa Eleitoral de Conceição do Coité

Aplicação Streamlit para visualizar resultados municipais por seção.

## Dados
Coloque em `data/resultados.csv` as colunas: `ano,lat,lon,local,secao,vencedor_prefeito,candidato_prefeito,votos_prefeito,candidato_vereador,votos_vereador`.

Os dados finais devem ser preenchidos a partir dos arquivos oficiais do TSE.
